# Interactive Quiz Game

An interactive and responsive Quiz Game built using HTML, CSS, and JavaScript.

## Features

- Start and restart quiz functionality
- Multiple-choice questions
- Real-time score tracking
- Correct and incorrect answer feedback
- Question progress tracking
- Progress bar
- Final score and result message
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. Click the "Start Quiz" button to begin.
2. Read the question and select an answer.
3. The selected answer is checked automatically.
4. The score is updated when the selected answer is correct.
5. The quiz automatically moves to the next question.
6. After completing all questions, the final score and result message are displayed.
7. Click "Restart Quiz" to play again.
